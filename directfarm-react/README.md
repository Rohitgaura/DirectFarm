# 🌱 DirectFarm React

A web application built with **React.js** to connect farmers directly with buyers, eliminating the need for middlemen and enabling transparent, fair trade.

---

## 🚀 Features

- 👨‍🌾 Farmers can list their products directly
- 🛒 Buyers can browse and purchase fresh produce
- 🔍 Easy search and filter options
- 📱 Responsive design (works on mobile and desktop)
- ⚡ Fast and optimized with Create React App

---

- **Backend (Future scope):** Node.js / Express
